# Day Anchor PRD

## 1. 제품 정의

Day Anchor는 사용자가 매일 아침 자신의 일정, 체크리스트, 메모, 음성기록을 하나의 화면에서 정리하고 하루가 끝난 뒤 실행 결과를 회고할 수 있도록 돕는 개인 데일리 운영 앱이다.

## 2. 문제 정의

많은 사용자는 캘린더, 투두앱, 메모앱, 음성녹음 앱을 따로 사용한다. 이때 일정은 일정대로, 할 일은 할 일대로, 순간적인 생각은 메모앱에, 음성기록은 녹음앱에 흩어진다. 그 결과 하루가 끝난 뒤 “무엇을 계획했고, 무엇을 실행했고, 왜 밀렸는지”를 한 화면에서 확인하기 어렵다.

Day Anchor의 1차 문제정의는 다음과 같다.

> 사용자는 하루의 계획-실행-회고 흐름을 하나의 맥락에서 관리하고 싶지만, 기존 도구들은 일정·할 일·메모·음성기록을 분리해서 보여주기 때문에 하루 운영 상태를 직관적으로 파악하기 어렵다.

## 3. 핵심 사용자

- 매일 아침 하루 계획을 세우는 사람
- 일정과 체크리스트를 함께 관리하고 싶은 사람
- 중간중간 떠오른 생각을 빠르게 기록하고 싶은 사람
- 텍스트 입력보다 음성메모가 편한 순간이 많은 사람
- 취업 준비, 포트폴리오 제작, 업무 루틴 등 자기 주도 프로젝트를 관리하는 사람

## 4. 사용자 시나리오

### 시나리오 A: 아침 계획

1. 사용자가 아침에 앱을 연다.
2. 오늘 꼭 해야 할 일, 피해야 할 것, 집중 시간대를 입력한다.
3. 일정 블록과 체크리스트를 추가한다.
4. 오늘 보드에서 하루 운영판을 확인한다.

### 시나리오 B: 실행 중 기록

1. 사용자가 작업 중 떠오른 생각을 빠른 메모에 작성한다.
2. 현재 시간이 특정 일정 블록 안에 있으면 해당 메모가 자동으로 그 일정에 연결된다.
3. 텍스트 입력이 어렵다면 음성메모를 녹음한다.

### 시나리오 C: 정해진 시간 메모

1. 사용자가 특정 시간에 받을 메모 질문을 설정한다.
2. 해당 시간이 되면 알림이 뜬다.
3. 앱은 알림 내용을 메모로 자동 기록한다.

### 시나리오 D: 하루 회고

1. 사용자가 하루 회고 화면을 연다.
2. 완료율, 미완료 항목, 미룬 일정, 메모 수를 확인한다.
3. 미완료 항목을 내일로 넘긴다.
4. 오늘의 한 줄 회고를 작성한다.

## 5. MVP 범위

### Must Have

- 날짜별 오늘 보드
- 아침 1분 계획 입력
- 일정 블록 CRUD
- 체크리스트 CRUD
- 텍스트 메모 작성
- 음성메모 녹음 및 재생
- 하루 회고 요약
- 최근 7일 인사이트

### Should Have

- 메모와 현재 일정 자동 연결
- 정해진 시간 메모 알림
- 미완료 항목 내일로 넘기기
- JSON 백업/복원
- PWA 설치 설정

### Won't Have in MVP

- Google Calendar 양방향 동기화
- 팀 공유
- 네이티브 iOS/Android 위젯
- AI 자동 일정 추천
- 음성 텍스트 변환

## 6. 핵심 지표

- Daily Plan Created Rate: 하루 계획을 작성한 날짜 비율
- Task Completion Rate: 체크리스트 완료율
- Schedule Edit Count: 일정 추가/수정/삭제 이벤트 수
- Memo Capture Rate: 하루 메모 작성률
- Voice Memo Usage Rate: 음성메모 사용 비율
- Daily Review Completion Rate: 하루 회고 작성률
- Carry-over Task Rate: 내일로 넘긴 태스크 비율

## 7. North Star Metric

> Planned Day Completion Score

사용자가 아침에 계획한 하루가 실제로 얼마나 실행·기록·회고까지 이어졌는지를 보여주는 복합 점수다.
